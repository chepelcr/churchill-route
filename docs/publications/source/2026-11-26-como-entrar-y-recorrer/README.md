# Reel 03 · corte de trabajo

Esta carpeta conserva el corte local de 657 fotogramas del 26 de noviembre. Para exportar la edición de 1 112 fotogramas con las tomas de ACON y la feria, usá `publicaciones/reel-03/proyecto/` en `churchill-trailer`.

Este corte también consume la biblioteca vigente. `npm run studio`, `npm run render` y `node render-local.mjs --proof` preparan la marca desde el checkout del juego.
