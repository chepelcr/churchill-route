# Changelog

Una nota por FECHA de entrega, `YYYY-MM-DD.md`, en español. Registra **todo** lo
que cambió y el porqué de cada decisión — es la memoria del proyecto, no material
de prensa.

**Las publicaciones se fueron a `docs/publications/`** el 2026-08-17, junto con su
carpeta `img/`. La razón es que son dos cosas distintas y mezcladas se confundían:
este archivo tiene diecisiete notas de entrega el 2026-08-14 y unas quince son de
adentro. Un jugador no puede ver «el mundo se mide en metros», y meterlo en un
post o lo infla con ingeniería invisible o lo obliga a tirar cosas en silencio.

Acá va el porqué; allá va lo que se ve al manejar.
